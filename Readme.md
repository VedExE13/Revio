# Revio AI

An AI-powered learning platform that helps students upload notes, chat with documents, generate quizzes, and improve their study workflow.

## Tech Stack

### Frontend
- React
- TypeScript
- Tailwind CSS
- Vite

### Backend
- FastAPI
- PostgreSQL

### AI
- RAG
- OpenAI-compatible APIs

## Database Migrations

Generate a migration

```bash
alembic revision --autogenerate -m "message"
```

Apply migrations

```bash
alembic upgrade head
```

Show current revision

```bash
alembic current
```

Show migration history

```bash
alembic history
```

Rollback one migration

```bash
alembic downgrade -1
```
